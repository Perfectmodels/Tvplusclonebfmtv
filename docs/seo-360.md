# SEO & visibilité — lot 1
## Audit du code
La branche main examinée utilise Next.js 15, le dépôt public Supabase v2 et le back-office Supabase. Le basculement MySQL annoncé n'est pas visible dans ces fichiers ; confirmer l'environnement avant toute migration. Aucune écriture en base dans ce lot.
- Métadonnées existantes différentes entre URL courte et slug, origine canonique dépendante des en-têtes dans certains modes.
- Sitemap général existant sans sitemap Actualités, sans RSS éditorial propre ; liste sans déduplication ni images.
- NewsArticle existant, auteur collectif traité comme une personne, couverture sans texte alternatif, dates relatives.
- Pas de module SEO dédié dans le menu admin v2.
## Lot livré
Métadonnées partagées, origine canonique stable, noindex pour recherches et articles introuvables, données NewsArticle et dates lisibles, sitemap général dédupliqué avec images, sitemap Actualités (48 h, maximum 1000), RSS éditorial (50), audit des 100 derniers articles en administration. Le flux externe News 24 reste inchangé et n'est pas dans le sitemap général.
## Configuration et recette avant production
- Définir NEXT_PUBLIC_SITE_URL à l'origine du domaine public voulu, sans chemin. En l'absence de valeur, repli sur https://tvplusclonebfmtv.vercel.app ; ne pas conserver ce repli pour le domaine final.
- Exécuter npm ci, npm run typecheck, npm run build dans un environnement avec les accès de test. Aucun résultat de build n'est attesté ici.
- Contrôler /robots.txt, /sitemap.xml, /sitemap-news.xml, /rss.xml : statut HTTP, XML valide, URL canonique, données non fictives, encodage des caractères, articles récents et retrait des articles inactifs.
- Tester les URL /a et /article, les réponses 404, la recherche, le rendu HTML des métadonnées, les partages et les données structurées. Vérifier le logo et les couvertures réelles, les dates et l'auteur affiché.
- Vérifier /admin-v2/seo avec une session autorisée et sans session. Contrôler les chiffres sur des données réelles et sur panne du dépôt public.
- Vérifier les routes statiques du sitemap, ses limites de 50 000 URL et 50 Mo non compressés. Prévoir un index de sitemaps segmentés avant d'atteindre ces seuils ; le lot actuel limite le parcours à 49 000 articles.
- Soumettre les sitemaps dans Search Console après validation du domaine. Aucun résultat d'indexation n'est garanti.
