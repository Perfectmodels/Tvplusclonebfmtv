Le logo TV+ est un remplacement temporaire, pas une miniature originale. Les URL de détail utilisent le modèle de la page historique repéré dans le site. Ne pas exposer les URL SproutVideo payantes ni transformer automatiquement les entrées supprimées en publications.
Le catalogue MySQL non vide prime sur le secours. En cas d'indisponibilité ou de catalogue vide, le secours permet de consulter les fiches publiques. Après import et validation des deux catalogues, définir LEGACY_PROGRAMMING_FALLBACK=false. Le fichier SQL de récupération fourni à l'exploitant crée uniquement une table privée de transit, conserve les 503 lignes et leurs statuts. Il n'est pas une publication automatique. Vérifier les correspondances avec tvp_shows et tvp_episodes et les droits avant de transférer les sources vidéo. L'accès payant historique n'est pas contourné.
