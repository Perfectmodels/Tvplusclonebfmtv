# Installation API PHP LWS V3
Prérequis : PHP CLI 8.1+, PDO MySQL, cURL, bash, copie Git authentifiée du dépôt main. Dans cPanel > Domains, relever la racine documentaire exacte de api-v3.tvplusafrique.com (ne jamais choisir la racine du site principal). La configuration existante tvplus-v3-private.php reste à deux niveaux au-dessus de cette racine ; ne pas la déplacer, publier ni écraser. 
Depuis la copie Git à jour : bash deploy/lws/editorial/install-api.sh /chemin/absolu/racine-api-v3
Le script contrôle en lecture seule les colonnes requises, effectue php -l, sauvegarde les neuf fichiers dans un dossier privé HOME et installe exclusivement les fichiers PHP opérationnels. Il teste le domaine HTTPS réel, le numéro de version et les routes publiques puis le diagnostic authentifié avec la clé locale (sans l'afficher). En cas d'échec après installation, les anciens fichiers sont restaurés. Ne pas exécuter les scripts historiques de seed/migrate/setup-roles. Aucune migration SQL automatique, aucun changement de prix, de rôle ou d'encaissement. Le diagnostic signale les comptages des archives de transit, sans exposer de lien vidéo privé. Les archives restent en transit : le transfert final vers les tables éditoriales exige une décision de publication/droits et une déduplication.
Si le test privé local fonctionne mais Vercel refuse encore l'accès, vérifier la concordance de LWS_EDITORIAL_SERVICE_KEY et service_key dans les deux interfaces privées (sans partager les secrets). Vérifier LWS_EDITORIAL_API_URL=https://api-v3.tvplusafrique.com/. Après installation, contrôler /api/premium/plans sur le site Vercel et la création d'une offre par un administrateur autorisé ; ne pas activer les encaissements réels.
