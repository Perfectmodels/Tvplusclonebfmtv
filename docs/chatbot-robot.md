# Chatbot public TV+ Afrique — robot blanc et bleu
Le bouton de lancement n’affiche aucun libellé. La conversation est conservée en mémoire de page; les questions appellent le véritable /api/assistant, et les liens renvoient aux articles du site. L'administration n'affiche pas ce composant (SiteFrame).
Le fichier public/tvplus-robot.webp est un rendu du robot GLB fourni, pas une illustration inventée. La version GLB optimisée est livrée séparément : déposer tvplus-robot-optimized.glb dans public/ pour activer le rendu 3D. Le composant vérifie la présence du fichier et charge uniquement à l'ouverture la visionneuse model-viewer 4.0.0 depuis jsDelivr. Sur mobile, économie de données, échec WebGL ou absence du modèle, le rendu léger animé reste disponible. Le modèle 3D tourne au geste de l'utilisateur, flotte, et réagit aux états de recherche/réponse. Le mode mouvement réduit désactive les animations.
Recette : ouvrir/fermer, clic avatar, rotation au toucher, envoi d'une question et résultat réel, nouvel échange, erreur réseau, nouvelle conversation, accès direct, vérifier le mobile (320, 375, 430 px) et les réglages accessibilité.
